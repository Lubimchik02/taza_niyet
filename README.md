# Taza Niyet — мобильное приложение (Flutter)

Этап 4 — карта и список квестов своей организации: метки, карточка выбранного квеста, переключатель
«Карта / Список», фильтры (сегодня, эта неделя, сложность, до 3 км), объяснение перед геолокацией,
скелетон / пусто / ошибка. Карта — пакет flutter_map; адрес плиток задаётся при сборке:
`flutter run --dart-define=MAP_TILES_URL=https://api.mapbox.com/styles/v1/<стиль>/tiles/256/{z}/{x}/{y}@2x?access_token=<ключ>`
(плитки openstreetmap.org по умолчанию — только для разработки).

Этап 3 — выбор организации: объяснение перед запросом геолокации, «Рядом / Город / Все», поиск,
код приглашения, заявка → на рассмотрении → одобрена или отклонена, без организации вкладки недоступны.
Демо: коды TAZA2026 и ZHASYL; Bars Volunteers отклоняет заявку; решение приходит через 4 секунды.
Геолокация — через `LocationService` (демо: центр Астаны); пакет geolocator подключается на этапе 12.

Этап 2 — вход и регистрация (поверх этапов 0–1): приветствие (Apple, Google, ключ доступа, email/телефон),
ввод кода с таймером повторной отправки и лимитом попыток, двухфакторная защита и резервный код,
профиль нового пользователя (имя, год рождения), восстановление доступа, защита маршрутов.

Вход пока работает через демо-реализацию `FakeAuthRepository`:
код 000000 — неверный, 111111 — устарел, любой другой — вход; email на «2fa…» — с двухфакторной защитой;
номер +7 700 000 00 00 — ошибка сети. Настоящий вход (Supabase Auth, Sign in with Apple, Google,
passkeys, хранение токенов в Keychain/Keystore, лимиты попыток на сервере) подключается на этапе 12 —
экраны менять не придётся, меняется только реализация `AuthRepository`.

Этап 1 — заставка и онбординг (поверх этапа 0).

Этап 0 — каркас: дизайн-система (светлая и тёмная тема), компоненты со всеми состояниями,
переводы kk / ru / en, нижняя панель из четырёх вкладок, тесты кнопки.

## Как запустить на своём компьютере

1. Установите Flutter: https://docs.flutter.dev/get-started/install (для iOS нужен Mac с Xcode).
2. Откройте терминал в этой папке и создайте папки платформ (существующие файлы не перезаписываются):
   ```
   flutter create . --org kz.tazaniyet --project-name taza_niyet --platforms ios,android
   ```
3. Скачайте шрифт Manrope (бесплатный, лицензия OFL) с https://fonts.google.com/specimen/Manrope
   и положите в `assets/fonts/` файлы: `Manrope-Regular.ttf`, `Manrope-Medium.ttf`,
   `Manrope-SemiBold.ttf`, `Manrope-Bold.ttf`, `Manrope-ExtraBold.ttf`.
4. Обновите зависимости до последних версий и сгенерируйте переводы:
   ```
   flutter pub add go_router flutter_riverpod shared_preferences flutter_map latlong2 share_plus qr_flutter pdf package_info_plus url_launcher connectivity_plus flutter_local_notifications timezone supabase_flutter firebase_core firebase_messaging
   flutter pub get
   flutter gen-l10n
   ```
5. Нативная заставка (лист на фоне, пока запускается Flutter):
   ```
   dart run flutter_native_splash:create
   ```
6. Запуск и тесты:
   ```
   flutter run
   flutter test
   ```

Экран «Дизайн-система» открывается из вкладки «Профиль» (только в debug-сборке). Там же кнопка «Показать заставку и онбординг снова».

Заставка: полная анимация (~4,4 с) — только при первом запуске, дальше короткая (~0,8 с); при «Уменьшении движения» — без анимации.

## Структура

```
lib/
  main.dart                     — приложение, темы, языки
  core/theme/                   — токены (отступы, радиусы, анимации, тени), цвета, тема
  core/widgets/                 — кнопка, карточка, Tz, скелетон, пустой экран, ошибка, офлайн, росток
  core/ui/haptics.dart          — тактильный отклик
  core/settings/                — тема и язык (сохраняются)
  core/router/                  — навигация, 4 вкладки
  features/                     — экраны (сейчас заглушки, наполняются по этапам)
  l10n/                         — строки kk / ru / en
test/                           — тесты
```

## Правила

- Название «Taza Niyet» не переводится.
- Цвета и размеры — только из токенов (`context.colors`, `Space`, `Radii`, `Motion`).
- Каждый новый компонент — со всеми состояниями: обычное, нажатое, неактивное, загрузка, ошибка, пустое.
- Анимации 150–300 мс; при системном «Уменьшении движения» — без анимаций.
- Зоны нажатия ≥ 48; текст масштабируется системным размером шрифта.


## Этап 4b — порядок входа и инструкция
- Порядок: заставка → онбординг → регистрация/вход → профиль → один раз экран «Где вы находитесь?» → главная.
- Организация не обязательна: редирект на /org убран. На главной сначала карточка «Как это работает», после прочтения — мягкая карточка «Выберите организацию» (Выбрать / Позже).
- Иконка-решётка в шапке главной → /guide: 5 шагов + «Важно». Точка на иконке — пока инструкция не прочитана.
- Карта без организации показывает все квесты города (только просмотр) с подсказкой вступить.
- Выбор организации открывается поверх (push) с кнопкой «Назад»; из профиля — без отмены текущей.
- Новые флаги настроек: guideSeen, locationAsked (сбрасываются кнопкой «Показать онбординг снова»).


## Этап 5 — карточка квеста и запись
- `/quest/:id` — QuestDetailScreen: когда, где, описание, баллы Tz, сложность, команды (по 10 человек, у каждой свой старший).
- Кнопка внизу по состоянию: нет организации → «Вступить в организацию»; заявка на рассмотрении → ждать; квест чужой организации → только «Пригласить друзей»; есть места → «Записаться» (подтверждение в нижнем листе, для младше 18 — напоминание сказать родителям); мест нет → «Встать в лист ожидания» с номером.
- Запрещено: повторная запись и квесты, пересекающиеся по времени. Отмена — с подтверждением; меньше чем за сутки — предупреждение о поздней отмене.
- Приглашение друзей: системное «Поделиться» (share_plus) со ссылкой https://tazaniyet.kz/q/<id>; маршрут `/q/:id` ведёт в карточку. App/Universal Links — этап 11.
- Главная: «Мои записи»; на карте/в списке у квестов со записью — «Вы записаны» / «Лист ожидания №N».
- Демо: FakeSignupRepository; записи хранятся в памяти до перезапуска (на сервере — этап 12). Квест с названием на «!» имитирует ошибку сети.

## Этап 6 — смена
- «Я на месте» на карточке квеста: доступна за 30 минут до начала и до конца. Геометка засчитывается в радиусе 300 м; дальше — можно отметиться без геометки (подтвердит старший). Без разрешения на геолокацию — объяснение и выбор.
- Старший (`/quest/:id/team`): список команды — кто отметился сам (геометка), кого отметил старший вручную (значок руки), кто не пришёл; часы на человека — шаг 0,5 ч, не больше длительности квеста; «Закрыть смену» → отчёт координатору.
- Защита от «любимчиков»: ручные отметки и изменённые часы видны координатору отдельно; часы нельзя завысить; бонус старшему +10 Tz — только после подтверждения; отметки по геометке старший снять не может.
- После подтверждения — начисление часов и Tz (1 ч = 5 Tz), итог «Мои часы» на главной (портфолио — этап 8).
- Демо: переключатель «Режим старшего (демо)» в профиле; в debug-сборке — «Демо: начать смену сейчас» и «Демо: старший закрыл смену». Координатор в демо подтверждает через 4 с; настоящее подтверждение — в веб-кабинете координатора (этап 12).

## Этап 7 — чаты
- Вкладка «Чаты»: поиск, сортировка по последнему сообщению, превью, время, непрочитанные; значок с числом на вкладке (чаты «без звука» не считаются).
- Виды: чат команды (появляется при записи на квест; старший и координатор помечены), канал организации (пишет только координатор), личные — только с друзьями (поиск и добавление друзей — этап 9).
- Переписка `/chat/:id`: пузыри, разделители «Сегодня/Вчера», статусы «отправляется / отправлено / не отправлено — нажмите, чтобы повторить», до 2000 символов, памятка безопасности.
- Безопасность (требование App Store / Google Play для приложений с общением): долгое нажатие на сообщение → «Копировать / Пожаловаться / Заблокировать»; меню чата → «Без звука», «Пожаловаться», «Заблокировать / Разблокировать». Жалобы — в очередь модерации (ответ в течение суток), сообщения заблокированных скрываются.
- Нагрузка: Supabase Realtime, канал на чат; при 10 000 одновременно пишущих нужен тариф без лимита расходов (до 10 000 подключений) — см. оценку в плане.
- Демо: FakeChatRepository; ответ собеседника через 2 с; сообщение со словом «!fail» имитирует ошибку отправки.


## Этап 8 — профиль и портфолио
- Профиль: аватар, имя, организация; часы · баллы Tz · смены; достижения (первая смена, три смены, 10 ч, командный игрок — 5 смен, 50 ч, старший) с прогрессом; история смен (подтверждённые и «ждёт подтверждения»); настройки профиля: кто видит часы, организация, режим старшего (демо).
- «Кто видит мои часы»: все / только друзья / только я. До 18 лет «Все» недоступно, по умолчанию — друзья.
- Портфолио `/profile/portfolio`: только подтверждённые координатором часы, «Подтвердила <организация>», QR (qr_flutter, всегда на белом фоне) и ссылка tazaniyet.kz/v/<номер> для проверки школой, вузом или работодателем; «Поделиться ссылкой». Номер — 8 символов без похожих 0/O/1/I; на сервере будет случайный токен с возможностью отозвать (этап 12). Публичная страница проверки — веб, этап 12; выгрузка PDF — этап 10 (экспорт данных).

## Этап 9 — главная, друзья, рейтинг
- Главная: поиск волонтёров → заявки в друзья (принять/отклонить) → подсказки (инструкция/организация) → мои часы → мои записи → рейтинг месяца (топ-3 + «Вы», организация/город, «Вы на N-м месте») → лента новостей (мои начисления, смены и достижения друзей, новые квесты организации).
- `/people`: поиск с 2 букв по началу имени или фамилии; часы видны прямо в результатах, если человек их не скрыл. `/people/:id`: часы · Tz · смены, достижения, «Добавить в друзья» → «Заявка отправлена» → «Написать»; меню — удалить из друзей, пожаловаться, заблокировать.
- Видимость: «все» / «друзья» / «только я»; до 18 лет — только друзьям. В рейтинге — только те, чьи часы мне видны, и только подтверждённые часы за текущий месяц; одинаковые часы — одно место.
- Дружба взаимная; личные чаты — только с друзьями (список чатов строится из друзей).
- `/rating`: полный рейтинг. Демо: FakePeopleRepository (12 волонтёров), заявка принимается через 3 с.


## Этап 10 — настройки
- Профиль → шестерёнка → `/settings`, 9 разделов (`/settings/<раздел>`):
  1. Аккаунт — имя (изменить), год рождения (только через поддержку), способ входа (замаскирован), «Выйти».
  2. Безопасность и вход — двухфакторная защита (при включении — 8 резервных кодов), ключи доступа (passkey), активные сеансы: «Завершить» и «Завершить все другие».
  3. Уведомления — смены, подтверждение часов, чаты, заявки в друзья, квесты организации, новости (по умолчанию выкл.), тихие часы 22:00–08:00.
  4. Приватность — кто видит часы (до 18 — без «Все»), кто может добавить в друзья, показ в поиске и рейтинге, список заблокированных с «Разблокировать».
  5. Язык и оформление — системный/қазақша/русский/English; тема системная/светлая/тёмная.
  6. Доступность — размер текста 100–150 % поверх системного, «Меньше анимации», вибрация при нажатиях (применяются ко всему приложению в main.dart).
  7. Мои данные — портфолио в PDF (пакет pdf, шрифт Manrope из assets — в стандартных шрифтах PDF нет кириллицы/казахских букв; QR внутри) и все данные в JSON; отправка через системное «Поделиться».
  8. О приложении и помощь — инструкция, поддержка help@tazaniyet.kz, политика конфиденциальности, условия, лицензии, версия.
  9. Удаление аккаунта — что удалится, что останется (часы в отчётах организаций без имени), 30 дней на отмену, совет скачать PDF, подтверждение словом «УДАЛИТЬ» (требование App Store / Google Play). На сервере перед удалением — повторный вход кодом (этап 12).
- Демо: 2FA, ключи доступа и сеансы — имитация; реальные — Supabase Auth (этап 12). Ссылки tazaniyet.kz/privacy и /terms нужно опубликовать до подачи в магазины (этап 13).

## Этап 11 — уведомления, ссылки, офлайн, обновления, флаги
- **Уведомления.** Колокольчик на главной → `/notifications` (непрочитанные выделены, «Прочитать все», нажатие открывает нужный экран). Сюда приходят: часы подтверждены, организация одобрила, друг принял заявку, напоминания. Разрешение спрашиваем мягко — после первой записи на квест («Напомнить о смене?»), системный запрос только по «Разрешить» и один раз. Напоминания за день и за час — локальные (flutter_local_notifications + timezone, работают без сети), отменяются при отмене записи. Серверные пуши (FCM/APNs) — этап 12: нужен Firebase-проект, `google-services.json`, `GoogleService-Info.plist`, ключ APNs.
- **Ссылки.** `tazaniyet.kz/q/<квест>` → карточка квеста, `/v/<номер>` → проверка портфолио (открывается и без входа), `/u/<id>` → профиль волонтёра, `/join/<код>` → вступление по коду. Настройка: Android — intent-filter с `android:autoVerify="true"` для https://tazaniyet.kz в AndroidManifest и файл `web/.well-known/assetlinks.json` на сайте (подставьте SHA-256 ключа подписи из Play Console); iOS — Associated Domains `applinks:tazaniyet.kz` и `web/.well-known/apple-app-site-association` (подставьте Team ID). go_router обрабатывает путь сам (Flutter deep linking включён по умолчанию с 3.27).
- **Без сети.** Тёмная полоса «Нет сети — показаны сохранённые данные»; квесты — последний загруженный список. «Я на месте» работает без связи: время и геометка сохраняются в очереди (`outbox`, хранится на устройстве) и уходят, как только сеть появится; сообщения в чатах — так же. При появлении сети — «Сеть появилась — всё отправлено». Полный офлайн-кэш (SQLite) — этап 12.
- **Обновления.** Удалённая конфигурация: `minVersion` — ниже неё экран «Нужно обновить приложение» (нельзя закрыть), `latestVersion` — мягкая полоса «Доступна новая версия» с «Обновить» и ×.
- **Флаги функций.** chats / rating / feed можно выключить удалённо без выпуска новой версии (вкладка «Чаты» становится неактивной, блоки рейтинга и ленты скрываются).
- **Для разработчика** (только debug): Настройки → «Для разработчика (демо)» — нет сети, новая/старая версия, флаги, открыть ссылку, тестовое уведомление.


## Этап 12 — сервер (Supabase)
- 12a: база и логика — папка `supabase/` (см. `supabase/README.md`), список аккаунтов — `ACCOUNTS.md`.
- 12b: приложение подключено к серверу. Запуск с сервером:
  ```bash
  flutter run --dart-define=SUPABASE_URL=https://<проект>.supabase.co --dart-define=SUPABASE_ANON_KEY=<anon-ключ> \
              --dart-define=MAP_TILES_URL=<плитки>
  ```
  Без этих параметров — демо-режим, как раньше (Fake-репозитории).
- `lib/core/backend/`: `backend.dart` (подключение), `supabase_auth.dart` (вход кодом на почту/СМС, Apple/Google через OAuth, вторая ступень TOTP, профиль с согласием), `supabase_data.dart` (организации, квесты, запись, смена, люди и друзья, чаты с Realtime), `backend_sync.dart` (при входе — конфигурация, членство, начисления, записи, друзья, уведомления; новые уведомления в реальном времени обновляют нужные данные).
- Пуши: `lib/features/notifications/push_service.dart` (FCM-токен → `register_push_token`, нажатие на пуш открывает экран) и `supabase/functions/push` (уведомление → FCM на телефоны, язык пользователя, его переключатели и тихие часы 22:00–08:00). Нужны Firebase-файлы и секрет `FCM_SERVICE_ACCOUNT` (ACCOUNTS.md). Webhook: Database → Webhooks → `notifications` INSERT → функция `push`.
- Согласие на обработку персональных данных — обязательная галочка на экране профиля (ссылка на политику; для младше 18 — «прочитайте вместе с родителями»). Текст согласия и политику должен проверить юрист.
- На сервере: ключей доступа (passkey) нет — кнопка скрыта; резервных кодов второй ступени нет — восстановление через поддержку; номер портфолио — случайный с сервера (`my_portfolio_code`), проверка — `verify_portfolio` (без входа).
- В Supabase → Auth → URL Configuration добавить `kz.tazaniyet.app://login-callback`; в AndroidManifest/Info.plist — схема `kz.tazaniyet.app`.
- 12c: веб-кабинет координатора `web/coordinator/` и публичная проверка портфолио `web/v/` (см. `web/README.md`); серверные функции — `supabase/migrations/…0600_coordinator.sql`.
