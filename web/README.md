# Веб-страницы Taza Niyet (этап 12c)

| Папка | Что это | Где разместить |
| --- | --- | --- |
| `coordinator/` | Кабинет координатора: заявки, квесты и старшие, отчёты смен (ручные отметки выделены), подтверждение часов, штраф старшему, волонтёры и роли, канал, жалобы | любой статический хостинг, например `admin.tazaniyet.kz` |
| `v/` | Публичная проверка портфолио по номеру (для школ, вузов, работодателей) | `tazaniyet.kz/v/` — чтобы ссылки `tazaniyet.kz/v/<номер>` открывали её |
| `.well-known/` | Файлы для открытия ссылок прямо в приложении | `tazaniyet.kz/.well-known/` |

Обе страницы — один HTML-файл без сборки. Подключение: в начале файла впишите `tn-supabase-url` и `tn-supabase-anon` (публичный ключ). Пусто — демо-режим на тестовых данных.

Кабинет входит по коду на почту (Supabase Auth). Пускает только тех, у кого в организации роль «координатор»; все действия проверяет сервер (`supabase/migrations/…0600_coordinator.sql`). Первого координатора назначьте в SQL-редакторе Supabase:

```sql
update memberships set role = 'coordinator', status = 'active'
where user_id = (select id from auth.users where email = 'coordinator@example.kz') and org_id = '<id организации>';
```

Хостинг страниц (как и базы) — на сервере в Казахстане, см. ACCOUNTS.md.
